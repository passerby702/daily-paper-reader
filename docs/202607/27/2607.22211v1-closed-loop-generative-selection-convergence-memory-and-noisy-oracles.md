## 摘要
闭环生成选择已成为计算药物发现的核心方法：学习型生成模型提出候选分子，适应度预言机对其进行评分，保留最优分子，并在下一轮之前对该精英集重新训练模型。尽管该方法应用广泛，但缺乏严格的收敛理论，这主要是因为每轮重新训练模型打破了经典进化算法分析所依赖的马尔可夫性。我们为这类算法建立了一套自洽的收敛性和期望运行时间理论。通过恢复扩大状态空间上的马尔可夫结构，我们证明了精英主义使搜索具有吸收性，并证明了几乎必然收敛性以及一个将搜索分解为逃离每个适应度级别所需时间的运行时间界。然后，我们分析了模型记忆的作用——模型训练所用的历史数据量。当随着数据增多学习持续改进时，更深的内存从不会有害；当并非如此时，退出时间分析揭示了最佳记忆深度，并表明过多的记忆实际上会减慢收敛。该理论扩展到多目标搜索和噪声预言机：我们量化了在轻尾噪声下需要多少次重复评估才能保证进展，以及在重尾噪声下鲁棒估计器如何恢复保证。从预言机评估（药物设计的真正瓶颈）的角度重新表述，分析得出了一种具体的、评估最小化策略。一项可重复性研究证实了这些预测，包括过度记忆的惊人代价。我们以三个开放问题作为结尾。

## Abstract
Closed-loop generative selection has become a workhorse of computational drug discovery: a learned generative model proposes candidate molecules, a fitness oracle scores them, the best are kept, and the model is retrained on this elite set before the next round. Despite its wide use, the method has lacked a rigorous convergence theory, largely because retraining the model each round breaks the Markov property on which classical evolutionary-algorithm analysis relies. We develop a self-contained theory of convergence and expected running time for this class of algorithms. By recovering a Markov structure on an enlarged state space, we show that elitism makes the search absorbing, and we prove almost-sure convergence together with a runtime bound that decomposes the search into the time spent escaping each fitness level. We then analyse the role of the model's memory---how much of the past it is trained on. When learning improves steadily with more data, deeper memory never hurts; when it does not, an exit-time analysis pinpoints the optimal memory depth and shows that excess memory can actually slow convergence. The theory extends to multi-objective search and to noisy oracles: we quantify how many repeated evaluations certify progress under light-tailed noise, and how robust estimators restore guarantees under heavy tails. Recast in terms of oracle evaluations - the true bottleneck in drug design - the analysis yields a concrete, evaluation-minimal strategy. Areproducible study confirms the predictions, including the surprising cost of excess memory. We close with three open problems.

## 2. 方法论

### 2.1 核心思想
- **恢复马尔可夫结构**：由于种群过程 (P_t) 本身在自适应生成模型下一般不是马尔可夫链，论文通过扩大状态空间来恢复马尔可夫性：对于全记忆，采用历史过程 H_t = (P_0, ..., P_t)；对于有限 m 步记忆，采用滑动窗口 S_mt = (P_{t-m+1}, ..., P_t)。这两个扩大过程均为时间齐次马尔可夫链。
- **吸收性与单调性**：精英选择（top-N 保留）保证种群最优适应度单调不减，因此目标集（ε-最优分子）是吸收态，从而几乎必然收敛。
- **适应度水平法**：将搜索空间按适应度值划分为水平集 L_k，每个水平集的“逃逸概率” q_k（单次提出高于当前水平的分子的最坏情况概率）通过 M 次独立提出放大为 p_k = 1-(1-q_k)^M。期望击中时间可分解为每个水平期望逗留时间之和 ≤ Σ 1/p_k。
- **记忆分析**：在单调学习假设（Assumption 6，更多历史数据不降级逃逸概率）下，逃逸概率随记忆深度 m 单调递增，从而期望击中时间单调递减（记忆层级结构 Theorem 4.21）。当该假设不成立时（如滑动窗口平均导致陈旧偏差），论文给出退出时间分析，精确定位最优记忆深度为学习曲线 ρ_k(j) 的第一个峰值（Theorem 5.6）。

- **基本算法**：初始化池 P_0（N 个已评分分子），G_0。每轮：从 G_t 采样 M 个候选，评分，取 top-N 得 P_{t+1}，根据历史更新 G_{t+1}（全记忆、m 步记忆或单步）。

## 6. 主要结论与发现

1. **收敛性**：任何满足均匀正性的学习生成模型与精英选择结合，闭环生成选择几乎必然收敛到 ε-最优分子，尾部几何衰减。
2. **期望运行时间**：层状击中时间界 E[τε] ≤ Σ 1/(1-(1-q_k)^M)，其中 q_k 为最坏情况逃逸概率。当 M q_k ≪ 1 时近似为 (1/M) Σ 1/q_k。
3. **记忆深度的影响**：
   - 在单调学习假设下，记忆深度越大，逃逸概率越高，期望击中时间越短（记忆层级结构）。
   - 当单调性不成立时（如滑动窗口平均导致陈旧偏差），存在有限的最优记忆深度 m*_k，由学习曲线 ρ_k(j) 的第一个峰值决定；过度记忆反而减慢收敛（U 形曲线）。
4. **评估最小化**：预言机评估次数在 M=1（顺序提议）时最小，结合内存与早停可进一步降低。给出了评估-轮数 Pareto 前沿。
5. **噪声预言机**：
   - 亚高斯噪声下需要重复查询以置信度认证分子，代价因子 σ²/Δ² ln(2/δ)。
   - 重尾噪声下样本均值失效，中位数均值或符号检验可在有限矩或无矩条件下恢复正确性，但评估次数随尾厚增加。
   - 自适应边界采样策略（Algorithm 3）在保持正确性的同时减少评估次数。
6. **多目标扩展**：通过超体积指标，所有结果自然推广到多目标优化，只需将适应度换为超体积值。

## 8. 不足与局限

- **实验外部有效性有限**：仅使用 OneMax 玩具问题，未在真实化学空间（如分子图、SMILES）或真实 oracle（如对接评分、ADME 预测）上进行验证。OneMax 是单调、可分离的，而真实分子空间具有复杂依赖和非凸性。
- **缺乏对复杂生成模型的量化**：逃逸概率 q_k 及其记忆依赖版本 q^m_k 被抽象设为已知下界，但论文未给出如何从神经网络生成模型（如 VAE、扩散模型）中导出或估计这些概率的具体方法。这限制了理论对实际系统的直接应用。
- **记忆分析在强假设下精确**：非单调退出时间理论在“组成同质性”（composition-homogeneity，逃逸概率仅依赖当前水平池个数）下才准确，而普通滑动窗口平均只近似满足。水平自适应策略的增益在实验中未完全显现（作者指出 naive windowed learner 不完美）。
- **噪声处理假设**：符号检验要求噪声对称；实际药物设计中的噪声可能不对称（如系统偏差）。重尾分析限于对称情况。
- **仅处理离散有限空间**：连续表示（如分子自动编码器的潜在空间）未正式处理，虽提到可采用 Meyn-Tweedie 稳定性理论，但未展开。
- **期望界而非高概率界**：击中时间和评估成本仅给出期望上界，未提供高概率保证或尾部分布（虽然 Theorem 3.3 给出了几何尾部，但常数依赖 α 可能极小）。
- **未考虑多保真度或代理模型**：实际药物发现可能使用多保真度 oracle（低精度虚拟筛选→高精度体外实验），论文未涵盖这一重要维度。
- **计算效率分析缺失**：虽然主张评估最小化，但未讨论生成模型本身的训练成本（重训练周期），后者在深度神经网络中不可忽略。

## 9. 整体评价与未来方向

- **理论贡献**：该论文首次为闭环生成选择（尤其在药物发现中常见但理论缺失的迭代重训练场景）提供了自洽的收敛与记忆分析框架。其核心创新在于通过状态空间扩恢复马尔可夫性，将分析聚焦于预言机评估次数（实际瓶颈），并证明了顺序提议（M=1）在期望评估次数上的最优性。这些结果为现有“生成-筛选”循环的无启发式工程实践提供了理论依据和优化指导。
- **实用价值**：尽管实验局限于 OneMax 函数，但其所揭示的规律（记忆深度的 U 形效应、噪声认证代价、自适应边界采样策略）对真实分子搜索具有重要参考意义。特别是重尾噪声下符号检验的适用性分析，为处理 oracle 噪声（如实验误差、计算精度波动）提供了鲁棒策略。
- **未来工作延伸**：
  - **真实空间验证**：将框架扩展到分子图、SMILES 或潜在空间，使用真实 oracle（如对接得分、ADME 预测）进行实证，并评估逃逸概率 q_k 在实际生成模型（如 VAE、扩散模型）中的可估计性。
  - **多保真度集成**：结合低成本代理模型与高成本精确 oracle，在理论框架中引入预算分配与自适应保真度选择。
  - **连续域与稳定性**：利用 Meyn-Tweedie 稳定性理论扩展至连续状态空间，并处理非精英选择（如随机选择）的收敛条件。
  - **生成模型训练成本**：将生成模型每轮的重训练代价纳入总预算分析，探讨“训练-采样”最优权衡，论文当前仅考虑 oracle 评估成本。
  - **高概率保证**：将期望击中时间界加强为高概率尾界，并探索逃离概率 q_k 具有更紧下界的估计方法。
- **局限总结**：论文在数学推导上严谨，但实验外部有效性有限、对神经网络生成模型的参数化逃逸概率缺乏显式指导、未覆盖多保真度场景及生成模型训练开销。尽管如此，作为首个针对自适应闭环生成选择的理论研究，它为后续在真实药物发现场景中的算法设计与分析奠定了坚实基础。
