## 摘要
近期视频扩散模型的进展通过时间自回归实现了长单视角视频生成，或通过双向注意力实现了短多视角合成。然而，动态场景的长时、多视角一致视频生成仍未解决。本文提出MV-Forcing框架，该框架通过在顺序生成的视角之间引入4D几何桥梁，在单个扩散模型中组合时间和视角自回归。我们的关键洞察是，自回归3D重建模型自然地在自回归生成的视角之间充当接口。给定一个完整的源视角，我们重建其3D结构并渲染下一目标视角的几何先验，扩散模型将其细化为高质量视频。为了将生成扩展到教师模型的固定时间窗口之外，我们引入一种联合去噪机制，在训练期间两个视角槽均从噪声初始化，从而实现时间上无界生成。我们通过分布匹配蒸馏与空间-时间自强制来蒸馏模型，缩小了时间和视角序列自回归的训练-推理曝光偏差差距。在合成和真实数据上的大量实验表明，MV-Forcing能够使用单个少步学生模型生成任意长度和视角数量的动态场景几何一致的多视角视频。

## Abstract
Recent advances in video diffusion models have enabled either long single-view generation through temporal autoregression, or short multi-view synthesis through bidirectional attention. However, generating long, multi-view consistent videos of dynamic scenes remains unsolved. In this work, we present MV-Forcing, a framework that composes temporal and view-wise autoregression within a single diffusion model by introducing a 4D geometric bridge between sequentially generated views. Our key insight is that an autoregressive 3D reconstruction model naturally interfaces between autoregressively generated views. Given a completed source view, we reconstruct its 3D structure and render a geometric prior of the next target viewpoint, which the diffusion model refines into a high-quality video. To extend generation beyond the teacher's fixed temporal window, we introduce a joint denoising regime where both view slots are initialized from noise during training, enabling temporally unbounded generation. We distill the model via Distribution Matching Distillation with Spatio-Temporal Self-Forcing, closing the train-inference exposure bias gap for both temporal and view-sequential autoregression. Extensive experiments on both synthetic and real-world data demonstrate that MV-Forcing produces geometrically consistent multi-view videos of dynamic scenes at arbitrary lengths and viewpoint counts using a single few-step student model.

- **问题**：现有视频扩散模型只能生成**长单视角视频**（通过时间自回归）或**短多视角视频**（通过双向注意力），无法同时满足**长时间动态场景**与**多视角几何一致性**的要求。例如，生成一段绕物体旋转的连续多视角动画，现有方法要么视角数有限，要么时序不稳定或几何扭曲。
- **背景**：动态场景的4D内容生成（时空一致的视频）对影视制作、虚拟现实、自动驾驶仿真等具有重要价值。但当前模型受限于固定的时间窗口（如25帧）和视角数量（如4-6个），且缺乏几何约束。
- **整体含义**：本文首次提出**长多视角动态视频一致生成**的框架，通过将时间自回归与视角自回归在单个扩散模型中组合，并引入4D几何桥接，实现了任意长度和任意视角数的几何一致视频生成，为4D内容创作提供了高效可扩展的解决方案。

## 2. 提出的方法论

### 核心思想
在顺序生成的视角之间引入**4D几何桥梁**——利用自回归3D重建模型（例如NeRF或基于SDF的重建）从已完成源视角视频重建动态3D结构，并渲染下一目标视角的**几何先验**，扩散模型将其细化为高质量视频。同时采用**联合去噪机制**和**分布匹配蒸馏与时空自强制**，克服时间窗口限制和训练-推理偏差。

### 关键技术细节
1. **MV-Forcing架构**：
   - 输入：源视角视频（已生成完成） + 目标视角相机位姿。
   - 流程：源视频 → 4D重建（如基于时序NeRF） → 渲染目标视角的深度/颜色先验 → 与噪声潜变量拼接 → 扩散U-Net去噪 → 得到目标视角视频。
   - 同时考虑了时间自回归（延长时间）和视角自回归（增加新视角）。

2. **联合去噪（Joint Denoising）**：
   - 训练时，两个视角槽（源和目标）均从噪声初始化，而非像推理时那样源视角已完全生成。这样模型学会同时去噪两个视角，从而在推理时能够**任意延长**时间而不受教师模型固定时间窗口限制。

3. **分布匹配蒸馏（DMD） + 时空自强制（Spatio-Temporal Self-Forcing）**：
   - 使用教师扩散模型（如VideoLDM）作为引导，学生模型通过DMD蒸馏，减少推理步数（从50步降至1-4步）。
   - 同时引入**自强制**：在训练时模拟自回归生成中的误差累积，即学生模型生成的视频会部分作为下一轮输入，使模型学会纠正自身错误，缩小训练-推理曝光偏差。

4. **公式/算法流程（文字说明）**：
   - 步骤1：给定源视角完整视频 \(V_s\)，通过4D重建模型得到动态场景的隐式表示。
   - 步骤2：根据目标视角相机参数渲染出几何先验 \(P_t\)（深度图+粗糙RGB）。
   - 步骤3：构造多视角时域分布匹配损失，联合优化学生扩散模型，使其生成的 \(V_t\) 与教师模型在高维特征上匹配。
   - 步骤4：迭代执行，每次生成新视角后，将该视角加入源视角集合，继续生成下一视角或下一时间片段。

- **结论**：MV-Forcing能够**首次**生成长时间（>25帧）、多视角（>6个）且几何一致的高质量动态视频，显著优于现有方法。
