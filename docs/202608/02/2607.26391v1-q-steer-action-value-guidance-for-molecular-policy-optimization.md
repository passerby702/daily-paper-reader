## 摘要
受限于Oracle的分子优化仅在生成完整分子后才给出奖励，而每次展开都需要许多局部的下一令牌决策。这种延迟反馈接口使得分子策略优化变得短视：优化器可以学习到某个分子是好的，但不知道是哪些中间动作使其变好。我们引入了Q-Steer，一种用于分子语言模型的展开时动作价值引导原语。Q-Steer使用一个离线训练且冻结的前缀-动作价值评分器PAVS-Q，该评分器估计在部分SMILES前缀下采取候选下一令牌的下游奖励，然后将归一化的价值奖励加到采样对数几率上。优化器的更新规则和在线Oracle预算保持不变；其主张是固定的在线Oracle性能，而非相等的总计算量。在PMO23上，使用固定的10,000次在线调用预算，跨越两种分子语言模型骨干和四种优化器的完整析因研究表明，Q-Steer在所有八个骨干-优化器组合中均提高了平均有效唯一分数，宏观平均分数增益在+0.033至+0.049之间，每个组合有18-20个任务获胜。机制对照表明动作身份很重要：前缀广播价值几乎中性，而打乱的动作价值则损害性能。这些结果支持Q-Steer作为一种可复用的展开时动作价值包装器，在不改变在线Oracle预算的情况下，跨优化器家族和策略骨干提高了平均分子优化奖励。

## Abstract
Oracle-limited molecular optimization gives reward only after a complete molecule is generated, while each rollout requires many local next-token decisions. This delayed-feedback interface makes molecular policy optimization myopic: an optimizer can learn that a molecule was good without knowing which intermediate actions made it good. We introduce Q-Steer, a rollout-time action-value steering primitive for molecular language models. Q-Steer uses an offline-trained and frozen prefix-action value scorer, PAVS-Q, that estimates the downstream reward of taking a candidate next token under a partial SMILES prefix, then adds a normalized value bonus to sampling logits. The optimizer update rule and online oracle budget are unchanged; the claim is fixed-online-oracle performance, not equal total compute. On PMO23 with a fixed 10,000-call online budget, complete factorial studies across two molecular language-model backbones and four optimizers show that Q-Steer improves mean valid-unique score in all eight backbone-optimizer cells, with positive macro mean-score gains between +0.033 and +0.049 and 18-20 task wins per cell. Mechanism controls show that action identity matters: prefix-broadcast values are nearly neutral, while shuffled action values harm performance. These results support Q-Steer as a reusable rollout-time action-value wrapper that improves average molecular optimization reward across optimizer families and policy backbones without changing the online oracle budget.

# Q-Steer：用于分子策略优化的动作价值引导（论文详细总结）

## 1. 核心问题与研究动机

- **问题背景**：在受Oracle（属性打分器）预算约束的分子优化任务中，算法只能在生成完整有效分子后获得一次奖励信号。一个SMILES分子由大量逐token决策构成，但奖励无法归因到具体的中间动作，形成典型的**延迟反馈（delayed feedback）**问题。
- **核心痛点**：现有强化学习方法（REINVENT、PPO等）在整体优化框架上是有效的，但其 rollout 策略在每一个局部前缀处是**短视的**——生成器不知道在当前部分分子中"下一个选择哪个token"能导向高分分子。这种局部信用分配瓶颈限制了平均生成质量。
- **现有方法的局限**：
  - 修改生成器或优化器需要大量的重新设计和训练成本；
  - 状态价值函数 V(x<t) 只能判断"前缀是否有希望"，无法区分同一前缀下的不同候选动作；
  - 终端奖励模型/reranker只能在完整分子生成后打分，不干预采样过程本身。
- **本文主张**：在**不修改优化器更新规则、不增加在线Oracle调用次数**的前提下，通过一个离线训练的、冻结的动作价值评分器，在每次采样时为候选token注入局部前瞻信息，使策略的每步动作"看得更远"。

## 2. 方法论：Q-Steer 与 PAVS-Q

### 2.1 核心思想
- 训练一个**前缀-动作价值评分器 PAVS-Q**（Prefix-Action Value Scorer），离线估计"在当前SMILES前缀 x<t 下选择候选token a 所能获得的期望下游奖励"：
  ```
  Qϕ(x<t, a) ≈ E[R(x) | x<t, xt = a]
  ```
- 与其他方法的区别：
  - 状态价值（PAVS）只区分前缀好坏，无法区分的同一前缀下不同动作；
  - 终端重排器只作用于完整分子；
  - Q-Steer 在**采样过程中**直接改变每个token的概率分布，是真正的"动作级"引导。

### 2.2 PAVS-Q 的训练流程
- 从已有带奖励标记的分子数据中构建监督训练集：
  ```
  DQ = {(x<t, xt, y(x)) : t = 1, ..., T}
  ```
  其中 y(x) 为该分子的标准化终端奖励。
- 以均方误差（MSE）为损失训练：
  ```
  minϕ E(x<t, a, y)∼DQ [(Qϕ(x<t, a) − y)²]
  ```
- 网络结构：单层GRU前缀编码器（128维隐藏）+ 动作嵌入投影 + MLP头（LayerNorm、GELU、dropout）。
- 训练完成后冻结，在线优化阶段不接收任何梯度、奖励或在线轨迹信息。

### 2.3 Q-Steer 采样时的引导公式
在每次采样时：
1. 基座优化器给出候选动作 logits ℓt(a)；
2. PAVS-Q 对当前前缀的所有有效动作打分；
3. 对分数做局部归一化（中心化 + 缩放）：
   ```
   Q̄t(a) = (Qϕ(x<t, a) − μt) / (σt + ε)
   ```
4. 形成有界奖励（bounded bonus）：
   ```
   bt(a) = clip(β · Q̄t(a), −c, c)
   ```
   默认 β = 0.5，c = 5.0；
5. 将奖励加到原始logits上：
   ```
   ℓ̃t(a) = ℓt(a) + bt(a)
   ```
6. 按 softmax(ℓ̃t) 采样，生成完整分子后交给原优化器更新（更新过程完全不变）。

### 2.4 方法定位
- **不是后验重排器**：在每一步token采样前起作用；
- **不是新的PPO loss或REINVENT目标**：完整分子和奖励仍按原优化器逻辑更新；
- **不是多样性机制**：本质上是"利用性"（exploitation）导向的集中搜索工具；
- 文章从 Doob h-transform 的角度做了理论联系：将局部转移概率向高价值方向倾斜，但由于 PAVS-Q 是学习得到且经过归一化/裁剪，并非严格意义上的定理级 Doob 变换。

## 6. 主要结论与发现

1. **全组合正收益**：在全部 8/8 个骨干-优化器组合下，Q-Steer 均提升平均有效唯一分子分数，宏观增益范围 **+0.033 至 +0.049**，每组在 18~20/23 个任务上胜出。
2. **跨优化器的可复用性**：不依赖PPO特性，REINVENT、AHC、Hill-climbing 同样受益，说明它是"采样时包装器"而非"特定优化器补丁"。
3. **骨干稳健性**：LSTM 和 GPT2 上趋势一致，说明不是LSTM独有现象。
4. **机制确认**：正确动作-值映射带来的收益无法用简单的logit扰动、熵减少或前缀质量解释——动作身份至关重要。
5. **回报与多样性权衡**：所有组合的唯一性均下降，属于"利用型"工具，不是"探索型"机制。
6. **上尾发现混合**：Top-10和best-score的改善不稳定，部分组合（如LSTM PPO）Top-10 AUC接近中性；Q-Steer不算是"最佳分子发现"的普遍提升器。
7. **有效性略有下降**：非PPO优化器的有效性有轻微下降（如LSTM Hill-climbing −0.0975），使用时需要留意。

## 7. 方法优点

- **模块化、即插即用**：作为采样时包装器，与任意生成式分子优化器可组合，无需修改优化目标；
- **在线预算友好**：不增加任何Oracle调用，只增加本地模型计算，紧扣实际应用中最昂贵的瓶颈；
- **解耦离线/在线成本**：PAVS-Q训练被视为离线先验、单独披露，科学比较口径清晰（fixed-online-oracle performance）；

## 8. 不足与局限

- **骨干覆盖有限**：仅验证LSTM和一种GPT2配置（24层、128维嵌入），未覆盖更大规模transformer或更现代的架构（如基于图的生成模型、扩散模型）。
- **多样性代价**：所有组合的唯一性均降低，尤其LSTM PPO 降幅达 −0.2101。若实际应用需要多样候选库，需配合显式多样性惩罚或自适应β调度。
- **运行时开销未完全解决**：PAVS-Q需在rollout时对候选动作分批打分，PPO引导比基线慢约1.88倍；文中未给出工程优化方案。
- **任务特定性**：PAVS-Q为每个PMO任务单独训练，跨任务迁移/公用模型尚未研究；
- **机制对照范围有限**：mechanism controls仅在 LSTM PPO 上做了完整验证，未扩展到所有优化器和骨干；
- **上尾改善不稳定**：Top-10和best-score结果混合，不适用于追求"单个最佳分子"的场景；
- **安全与风险**：若将引导目标设置为不安全或不良属性，可能会加速生成有害分子；实际部署需要安全过滤器与专家审查；
- **运行公平性局限**：部分运行时对比因硬件调度差异（如非PPO引导反而更快）不具备可比性，论文也主动承认这一点。
