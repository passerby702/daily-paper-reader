## 摘要
预训练在学习可迁移表示方面显示出强大的潜力，但在基于电子密度的分子学习中仍未得到充分探索。电子密度提供了分子电子结构的连续三维描述，既捕捉局部空间模式，又捕捉全局物理量。这引发了一个关键问题：电子密度场能否用于自监督预训练，以学习一个可跨不同电子结构相关任务迁移的共享表示？我们提出了ED-DiT，一种基于物理引导的扩散Transformer，用于电子密度点云的自监督预训练。ED-DiT通过在不同扩散噪声水平下重建被破坏和部分掩蔽的对数密度场来学习可复用表示。进一步引入电子数一致性约束以保持总电子质量。预训练编码器可适应于性质预测、开壳层/闭壳层分类、分子-电子密度检索以及分子条件电子密度预测。在六个EDBench任务上的实验表明，ED-DiT始终优于从头训练相同架构，尤其是在有限监督下。对于分子条件电子密度预测，它将RMSE从2.2474降至1.3753，并超越了现有基线。仅使用10%标签时，它将轨道能量预测RMSE从0.0293改善至0.0138。这些结果证明了基于物理引导的电子密度预训练在学习可迁移分子表示方面的有效性。

## Abstract
Pretraining has shown strong potential for learning transferable representations, yet it remains underexplored for electron-density-based molecular learning. Electron density provides a continuous three-dimensional description of molecular electronic structure, capturing both local spatial patterns and global physical quantities. This raises a key question: can electron-density fields be used for self-supervised pretraining to learn a shared representation that transfers across diverse electronic-structure-related tasks? We propose ED-DiT, a physics-guided Diffusion Transformer for self-supervised pretraining on electron-density point clouds. ED-DiT learns reusable representations by reconstructing corrupted and partially masked log-density fields across diffusion noise levels. An electron-number consistency constraint is further introduced to preserve the total electronic mass. The pretrained encoder can be adapted to property prediction, open-/closed-shell classification, molecule-electron-density retrieval, and molecule-conditioned electron-density prediction. Experiments on six EDBench tasks show that ED-DiT consistently outperforms the same architecture trained from scratch, especially under limited supervision. For molecule-conditioned electron-density prediction, it reduces RMSE from 2.2474 to 1.3753 and surpasses the available baseline. With only 10% labels, it improves orbital energy prediction RMSE from 0.0293 to 0.0138. These results demonstrate the effectiveness of physics-guided electron-density pretraining for learning transferable molecular representations.

- 现有研究大多将电子密度当作特定任务的输入或预测目标（如性质预测、密度预测、检索），缺乏一个**共享编码器**能否跨多种电子结构相关任务迁移的系统性验证。

## 2. 论文提出的方法论

**核心思想**：将电子密度场视为点云，使用扩散 Transformer 进行自监督预训练，在去噪重建过程中融入电子数一致性这一物理约束，从而学习既保留局部密度模式又满足全局物理一致性的可迁移表示。

**关键技术细节**：

1. **电子密度点表示**：每个分子表示为点集 P = {(rᵢ, ρᵢ, wᵢ)}，其中 rᵢ 为三维坐标，ρᵢ 为密度值，wᵢ 为采样权重（取 1/N_valid）。对密度取对数变换 dᵢ = log(1 + ρᵢ)，并对坐标做中心化和半径归一化。

2. **扩散 Transformer 编码器**：
   - 每个点 token 由输入 MLP（拼接坐标和密度特征）与位置 MLP（坐标）相加构成；
   - 时间步 t 经正弦位置编码后嵌入，通过自适应层归一化（AdaLN）调制 DiT 块；
   - 输出局部点特征和全局表示 h_P（对有效点特征取平均）。

3. **掩码扩散去噪预训练目标**：
   - 对 log 密度加噪：d̃ᵢ,ₜ = √ᾱₜ dᵢ + √(1−ᾱₜ) εᵢ；
   - 以 50% 概率掩码有效点，被掩码点输入噪声化的 log 密度，未掩码点提供干净上下文；
   - 模型预测注入噪声 ε̂ᵢ，仅在掩码点上计算 L_den = MSE(ε̂ᵢ, εᵢ)。

4. **电子数一致性约束（物理引导）**：
   - 将预测噪声反解为去噪后的密度 ρ̂ᵢ；
   - 构造混合密度场：掩码点用重建值、未掩码点用真实值；
   - 计算点采样电子数代理 N_p(ρ) = Σ wᵢρᵢ；
   - 施加约束 L_N = ((N_p(ρ_mix) − N_p(ρ)) / (N_p(ρ) + ε))²，使重建场的总电子质量与真实场一致。

5. **总预训练目标**：L_pre = L_den + λ_N L_N，结合局部去噪与全局物理一致性。

6. **下游适应**：
   - 性质回归/分类：全局表示接任务专属 head；
   - 分子–电子密度检索：双塔对比学习（ED 编码器 + 分子编码器），对称交叉熵损失；
   - 分子条件密度预测：分子编码器提取结构特征，通过零初始化的交叉注意力适配器（借鉴 ControlNet）注入预训练 ED 编码器，预测查询点密度值。

## 6. 论文的主要结论与发现

- ED-DiT 在 **全部六个 EDBench 任务**上一致优于从头训练的相同架构：
  - OE RMSE 从 0.0184 降至 0.0080；EC RMSE 从 43.46 降至 17.93；MM RMSE 从 0.5679 降至 0.1722；OCS AUROC 从 0.7193 提升至 0.9997；
  - MER 双向 Top-1 接近完美（0.9978/0.9986），远超 Geoformer 基线；
  - EDP MAE 从 0.4165 降至 0.1213，RMSE 从 2.2474 降至 1.3753，超过 HGEGNN 和 DeepDFT。
- **低标签场景增益尤为突出**：1% 标签时 OCS AUROC 从 0.5438 提升至 0.9693；10% 标签时 OE RMSE 降低 52.97%、MM RMSE 从 0.8999 降至 0.3818。

- 预训练使嵌入空间沿密度质量信号呈现更平滑的组织结构，说明表示对齐了物理结构信息。
- 误差分析显示：误差集中于局部密度高变化区域（Q4），且呈长尾分布——极端高密度点仍是主要挑战。

## 7. 优点

1. **问题新颖性**：首次系统研究三维电子密度场上的自监督预训练，并验证跨任务可迁移性，填补了该方向空白。

3. **统一表示、多种下游适应方式**：同一预训练编码器可同时支撑回归、分类、检索和密度场预测，展示了表示的通用性。
4. **公平且充分的对比**：以同架构 Scratch 为主要基线，清晰隔离预训练增益；同时对比 EDBench 官方基线和领域专用方法（DeepDFT）。
5. **低标签性能提升显著**：在 1%/10% 标签下增益大，具有较强实际应用价值。

## 8. 不足与局限

1. **基准覆盖有限**：仅在 EDBench 一个基准上评估，跨化学成分域（如药物分子、材料体系）、不同电子结构设置（如激发态、自旋态）的泛化能力未验证。
2. **空间分辨率受限**：每分子最多采样 2048 个点，对较大分子或高分辨率密度场的表达能力可能不足。
3. **计算开销**：全局自注意力的复杂度较高，论文未报告训练时间，扩展到大体系或稠密采样时可能成为瓶颈。
4. **物理约束的近似性**：电子数一致性基于点采样代理而非严格的连续场积分，且重建密度需 clip 以保持数值稳定，可能引入轻微偏差。
5. **极端高密度点仍是短板**：Q4 最高变化区域的 MAE/RMSE 仍远高于其他区域；P99.9 绝对误差达 28.07，最大误差与 Scratch 差别不大（2415 vs. 2461），说明极端值预测改进有限。
6. **基线适配性局限**：X-3D/PointVector-S 在 MER 任务上表现较弱，可能因其为通用点云设计、不适应密度场特性，对比时需谨慎解读。
7. **消融仅针对一个约束**：未系统消融掩码比例、扩散步数、token 构造方式等设计选择。
