## 摘要
扩散Transformer（DiT）因其可扩展性和对多模态任务的适应性，已成为生成建模中的核心架构。DiT由各向同性的Transformer块组成，并随深度逐步学习表征，其中去噪目标驱使后期层专注于细节重建。这导致表征质量下降以及编码器-解码器行为失衡。先前的方法如表征对齐（REPA）通过训练正则化鼓励更强的早期表征来缓解这一问题。另一种方式是采用U-Net风格的DiT架构，引入显式的多尺度编码器-解码器结构以改善收敛。但它们基于标准U-Net经验，使用可学习的空间下采样算子，这并不适合Transformer架构，引入了低效以及与交叉注意力和表征正则化等组件的兼容性问题。在这项工作中，我们提出了UDT，一种U-Net扩散Transformer，它通过数据自适应的令牌合并进行下采样和上采样，同时保持DiT的令牌维度，从而结合了DiT的表征能力与U-Net的编码-解码优势。我们的基线UDT架构优于现有的U-Net DiT，并在所有模型规模下达到了与REPA相当的性能。此外，通过架构优化和REPA，UDT在256x256 ImageNet上的XL模型规模下，在40个epoch内（约40倍更快的收敛速度）超越了SiT在1400个epoch时的7.9 FID（无CFG）。最后，它在使用CFG的情况下实现了强大的图像生成性能，使用SD-VAE在320个epoch时达到1.38的FID，使用VA-VAE在500个epoch时达到1.35的FID，为DiT提供了一种具有强实证优势的新骨干架构。

## Abstract
Diffusion Transformers (DiTs) have emerged as a core architecture in generative modeling due to their scalability and adaptability to multimodal tasks. DiTs comprise isotropic transformer blocks, and learn representations progressively across depth, where the denoising objective drives later layers to focus on fine-detail reconstruction. This results in degraded representation quality and an imbalanced encoder-decoder behavior. Prior approaches such as representation alignment (REPA) mitigate this by encouraging stronger early representations via training regularization. Alternatively, U-Net-style DiT architectures introduce explicit multi-scale encoder-decoder structures for improved convergence. But they build on standard U-Net wisdom via learnable operators for spatial downsampling, which are not well-suited to transformer architectures, introducing inefficiencies and compatibility issues with components such as cross-attention and representation regularization. In this work, we propose UDT, a U-Net diffusion transformer that combines the representation power of DiTs with the encoding-decoding benefits of U-Nets, through data-adaptive token merging for downsampling and upsampling, while preserving the DiT token dimension. Our baseline UDT architecture outperforms existing U-Net DiTs and achieves performance comparable to REPA across all model sizes. Furthermore, using architectural optimization and REPA, UDT outperforms SiT's 7.9 FID at 1400 epochs (w/o CFG) within 40 epochs (~ 40x faster convergence) for XL model size on 256x256 ImageNet. Finally, it achieves strong image generation performance with CFG, reaching FID of 1.38 (320 epochs) with SD-VAE and 1.35 (500 epochs) with VA-VAE, providing a new backbone for DiTs with strong empirical benefits.

# UDT：通过数据自适应令牌缩减调和U-Net与扩散Transformer——论文总结

## 1. 核心问题与研究动机

- **背景**：Diffusion Transformers（DiTs）由各向同性的 Transformer 块堆叠而成，已成为图像生成的主流架构，具有良好的可扩展性和多模态适应性。
- **核心问题**：DiT 的噪声预测目标使后期层过度聚焦于细节重建，导致表征质量在中后期达到峰值后下降，形成“编码阶段过深、解码阶段过短”的编解码不平衡；同时早期层表征较弱。
- **已有方案及不足**：
  - REPA 等表征对齐方法通过外部编码器或额外正则强化早期表征，但引入了额外模型和训练开销，且未从架构本身改善表示学习。
  - U-DiT、SiT↓/UREPA 等 U-Net 风格 DiT 通过固定邻域的可学习下采样实现多尺度建模，但会压缩 token 特征维度、破坏 token 多样性，且与 Transformer 的全局自注意力、交叉注意力和 REPA 对齐存在兼容性问题。
- **研究问题**：能否在保持 DiT 表征特性和自注意力机制的前提下，引入 U-Net 的编码器-解码器结构？

## 2. 方法论与关键技术

- **核心思想**：提出 UDT（U-Net Diffusion Transformer），用**数据自适应、无参数的 token 合并（Token Merging, ToMe）**替代传统可学习空间下采样/上采样，在保持 token 特征维度（hidden dimension）不变的前提下，只缩减 token 序列长度。
- **架构设计**：
  - 网络对称划分为编码器和解码器；第一层编码器和最后一层解码器保持全分辨率，并通过跳跃连接相连，确保每个原始 token 都有对应的噪声预测。
  - 编码器逐层进行 token 合并，每层减少 r 个 token，直到中间瓶颈层达到目标数量 \(N_{\text{Merge}}\)（消融实验中最佳为 112）。
  - 解码器利用编码器阶段记录的合并索引，逐步“反合并”（unmerge），恢复原始 token 布局。
- **Token 合并/反合并技术细节**：
  - 基于 key 的相似度进行 bipartite soft matching，仅保留最相似的 r 对 token。
  - 合并采用加权平均：公式为：
    \[
    x_{m} = (s_1 x_1 + s_2 x_2) / (s_1 + s_2)
    \]
    其中 \(s_1, s_2\) 表示每个 token 对应的原始 patch 数。
  - 合并后使用 proportional attention：\(\mathrm{softmax}(QK^T/\sqrt{d} + \log s)\)，以补偿 token 合并带来的注意力偏差。
  - 反合并时，将合并 token 复制回原始位置，并恢复大小信息。
- **与 REPA 的兼容**：
  - 由于未改变 token 维度，瓶颈特征可通过记录的合并索引反合并到原始 token 分辨率，从而直接与 DINOv2 等外部编码器的 patch 特征做对齐，无需额外适应模块或 manifold 正则。
- **增强版本 UDT+**：
  - 引入 log-normal 时间采样、RoPE、SwiGLU 等改进；RoPE 仅用于 token 数量保持 256 的首尾层，避免破坏合并后的位置索引。
- **长序列扩展**：
  - 在 patch size 为 1 或 512×512 分辨率下，先在前几个编码块用高合并率（如 50%）快速将长序列降到 256 token 规模，再继续渐进合并，以控制计算成本。

## 7. 优点

- **设计巧妙**：将 ToMe 从推理加速工具转为训练友好的多尺度建模工具，天然契合 Transformer 的 token 化表示。
- **保持 token 维度**：只减少序列长度而不改变特征维度，避免了下采样带来的表征混乱，也便于接入 REPA、交叉注意力等模块。
- **无参、数据自适应**：下/上采样无需额外可学习参数，且能根据 token 语义相似度合并冗余区域，保留关键细节。
- **计算效率高**：在获得更好 FID 的同时，大幅降低 GFLOPs（例如 UDT-XL/2 约为 SiT 的 77%）。
- **实验体系全面**：从架构评估、系统级对比、消融、到多类下游替换和应用，验证充分；
- **可扩展性**：支持 patch size 1、512×512 等长序列设置，不改变模型配置即可迁移。

## 8. 不足与局限

- **应用范围有限**：论文未探索视频生成、2K 以上分辨率等更复杂场景，自称需进一步研究。
- **对高合并率的依赖**：长序列设置依赖早期较高 token 合并率，若 patch 相似度高虽效率提升，但极端情况下可能丢失局部细节。
- **REPA 的额外依赖**：与 REPA 结合时需要预训练视觉编码器和额外对齐投影，并不完全“零附加”。
- **位置编码限制**：RoPE 只能在首尾层使用，因为中间层 token 因合并/反合并打破了原始位置对应关系，限制了位置信息建模。
